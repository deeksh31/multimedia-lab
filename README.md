# 🎥 Video Analyzer

A simple Python-based **Video Analyzer** that extracts important metadata and technical information from a video file.

This project was created as part of a **Multimedia Analyzer Lab** to understand how Python can be used to analyze multimedia files.

---

## 📌 Features

The Video Analyzer extracts:

### 📁 File Information
- File Name
- File Size
- Container Format
- Duration

### 🎬 Video Information
- Resolution
- Frame Rate
- Frame Count
- Video Codec
- Bit Rate

### 🔊 Audio Information
- Audio Codec
- Number of Channels
- Sampling Rate
- Audio Bit Rate

### 📝 Metadata
- Additional available video metadata

---

## 🛠️ Technologies Used

- **Python**
- **OpenCV**
- **OS Module**
